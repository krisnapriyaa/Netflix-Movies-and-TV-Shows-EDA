# Netflix Data Visualisation Dashboard

## Project Overview
This project explores the Netflix Movies and TV Shows dataset using Python and Plotly. It presents key insights through interactive visualisations to understand Netflix's content distribution, release trends, movie durations, ratings, and genres.

## Dataset
- **Dataset:** Netflix Movies and TV Shows
- **Source:** [Kaggle – Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **Records:** 8,807 titles
- **Features:** 12 columns

## Technologies Used
- Python
- Pandas
- Plotly
- Google Colab

## Visualisations
The dashboard includes six visualisation types:

1. **Bar Chart:** Compares the number of Movies and TV Shows.
2. **Line Chart:** Shows content release trends over the years.
3. **Histogram:** Displays the distribution of movie durations.
4. **Box Plot:** Compares movie durations across content ratings.
5. **Scatter Plot:** Explores the relationship between release year and movie duration.
6. **Treemap:** Displays the distribution of popular genres.

## Interactive Features
- Hover over charts to view detailed information.
- Zoom and pan to explore chart details.
- Use the dropdown filter to view Movies, TV Shows, or all content in the content-distribution chart.

## How to Run
1. Download or clone this repository.
2. Open the dashboard notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries if necessary:
   `pip install pandas plotly`
4. Upload `netflix_titles.csv` to the notebook environment.
5. Run the notebook cells.
